# Ink & Ash — support site

The support and privacy pages for the Ink & Ash iOS app, served by GitHub Pages.

- `index.html` — Support page (the App Store "Support URL")
- `privacy.html` — Privacy policy (the App Store "Privacy Policy URL")
- `style.css` — shared styling, matching the app's palette

Both URLs are referenced from the app's App Store Connect listing, so they
need to stay reachable for as long as the app is on sale.
